# Амба — AI-летописец странствий по Приморью

<img src="frontend/assets/amba.svg" width="120" align="right" alt="Амба — тигрёнок-летописец">

Веб-ассистент для путешествий по **Приморскому краю**: пишешь запрос обычными словами — получаешь готовый план поездки
в виде **старорусской грамоты** (буквица, киноварь, дореформенная орфография, кириллическая цифирь), с картой маршрута
на OpenStreetMap. План **сверяется с реальным миром**: режим работы мест, прогноз погоды, расписания транспорта,
заправки по пути, дневные лимиты для пешехода и велосипедиста.

> Командный проект Т-Банк × Сириус. Маскот — амурский тигрёнок **Амба** в мурмолке и с гусиным пером.

## Что внутри

| Требование | Как сделано |
|---|---|
| **1. Агентная логика** | Свой агентный цикл на FastAPI + OpenRouter tool calling (без фреймворков): системный промпт → модель выбирает тул → вызов → результат возвращается агенту → … → `submit_plan`. Независимые тулы вызываются параллельно. |
| **2. Веб-фронт** | HTML/CSS/JS без сборки. Запрос → «летопись трудов» агента в реальном времени (SSE) → грамота + карта Leaflet/OSM (бонус). |
| **3. Деплой** | `Dockerfile` + `docker-compose.yml` + `deploy/deploy.sh user@IP` — открывается в браузере по `IP:порт`. |
| **4. Eval** | 20 фиксированных запросов (`eval/queries.json`), метрики качество / токены / $ / время, 3 версии пайплайна, таблица в `eval/results/summary.md`. Прогон автоматизирован. |
| **5. Guardrails** | Пред-фильтр без LLM (другие регионы, нецелевые запросы, prompt injection) + отказ через тул `decline_request` + проверка, что все точки плана в Приморье. |

### Тулы агента и источники данных

| Тул | Что делает | Источник |
|---|---|---|
| `get_weather` | прогноз по дням: осадки, ветер, закат, риски | **Open-Meteo** (реальный API) |
| `build_route` | маршрут для машины / велосипеда / пешехода | **OSRM** по данным OSM (реальный API) |
| `geocode` | координаты места в Приморье | **Nominatim** (реальный API) + офлайн-справочник |
| `find_fuel_stations` | АЗС вдоль маршрута, максимальный перегон без топлива | **OSM Overpass** (реальный) + мок наличия бензина |
| `place_info` | справка о месте | **Википедия** REST API (реальный) |
| `search_places` | достопримечательности, режим работы, выходные дни | офлайн-датасет (41 место Приморья) |
| `find_lodging` | ночёвка рядом, цена, свободные места | офлайн-мок (по мотивам Островка / Tvil) |
| `public_transport` | автобусы, электрички, паромы туда-обратно | офлайн-расписание (по мотивам Яндекс Расписаний) |
| `find_events` | ярмарки, спектакли, кормление тигров | офлайн-датасет |

Если внешний API недоступен, тул не падает, а честно переключается на офлайн-оценку и пишет об этом агенту.

### Сверка плана («план должен сходиться»)

Валидатор (`backend/app/validator.py`) не зависит от LLM и проверяет:
лимит дней и даты из запроса • способ передвижения • ночёвку на каждую ночь и свободные места •
режим работы мест в нужный день и час • все точки в Приморском крае • прогноз погоды: велосипед и пеший маршрут
не под ливнем, уличные места не в темноте • ≤ 20 км пешком и ≤ 80 км на велосипеде в день •
на машине — проверены АЗС на длинном маршруте • на автобусе — рейсы существуют, ходят в этот день, успеваем на последний.
В версиях v2/v3 противоречия возвращаются агенту, и он исправляет план (до 2 попыток).

### Версии пайплайна (для эвала)

| | v1 — бейзлайн | v2 — улучшенная | v3 — лёгкая модель |
|---|---|---|---|
| Промпт | короткий | подробный: правила, ограничения транспорта | как v2 |
| Контекст | сырые ответы тулов (геометрия, почасовая погода, `\u`-эскейпы) | **сжатие**: только нужные поля, компактный JSON | как v2 |
| Guardrails | только промпт | пред-фильтр без LLM + промпт | как v2 |
| Сверка | только показывается | ошибки возвращаются агенту на исправление | как v2 |
| Модель | `MODEL_V1` | `MODEL_V2` | `MODEL_V3` (дешевле) |

## Как запустить

```bash
make install                 # venv + зависимости
cp .env.example .env         # впишите OPENROUTER_API_KEY (без ключа — демо-режим)
make dev                     # http://localhost:8000
```

Без ключа приложение работает на детерминированном демо-планировщике: тот же агентный цикл и те же тулы,
меняется только «мозг». Удобно для отладки фронта и тестов.

### Тесты

```bash
make test        # pytest (бэкенд: тулы, валидатор, агентный цикл, API, guardrails, эвал) + node:test (фронт)
```

Тесты не ходят в сеть: внешние API мокаются через `respx`, LLM — скриптованная.

### Эвал

```bash
make eval                                            # v1, v2, v3 на 20 запросах → eval/results/summary.md
.venv/bin/python eval/run_eval.py --versions v2 --limit 5   # быстрый прогон
make eval-demo                                       # проверка обвязки без LLM
```

**Качество** = 0,5 × «верный тул» + 0,5 × доля пройденных проверок сверки.
«Верный тул» — агент вызвал все обязательные для запроса тулы (для поездки на машине — маршрут и АЗС,
для автобуса — расписание и т. д.), а для нецелевого запроса корректно отказал, не собирая данных.
**Стоимость** — токены и $ из `usage` OpenRouter. **Скорость** — время от запроса до готового плана.

### Деплой на VM

```bash
./deploy/deploy.sh ubuntu@<IP> 8000     # rsync кода + .env, установка Docker, docker compose up
# → http://<IP>:8000
```

## Структура

```
backend/app/
  main.py          FastAPI: /api/plan, /api/plan/stream (SSE), статика
  agent.py         агентный цикл, версии v1–v3, обогащение карты
  llm.py           клиент OpenRouter, учёт токенов и стоимости
  prompts.py       системные промпты и JSON-схема плана
  tools/           9 тулов + офлайн-датасеты в data/
  validator.py     сверка плана с запросом и реальным миром
  intents.py       детерминированный разбор интентов (сроки, транспорт, даты)
  guardrails.py    пред-фильтр
  demo_llm.py      детерминированный планировщик для работы без ключа
  evaluation.py    метрики эвала
frontend/          index.html, styles.css, js/ (app, render, oldstyle), assets/amba.svg
eval/              queries.json, run_eval.py, results/
presentation/      build.js → Amba_Travel_AI.pptx
docs/REPORT.md     отчёт
```
